- **新场景 40** `ellipse-analytic` · 椭圆解析几何(王炸,高中解析几何 选修1)
  - **核心公式**:
    - **标准方程(王炸)**:x²/a² + y²/b² = 1  (a > b > 0,中心在原点,焦点在 x 轴)
    - **关键量**:a(长半轴)· b(短半轴)· c = √(a²-b²)(半焦距)· e = c/a(离心率,0 ≤ e < 1)· p = b²/a(半通径)
    - **第一定义(王炸)**:PF₁ + PF₂ = 2a(两焦点距之和恒定)
    - **第二定义(王炸)**:PF = e × Pd(与 39 conic-unified 等价,离心率公式)
    - **参数方程**:x = a·cosθ, y = b·sinθ(单位圆在 x/a、y/b 缩放),面积 = πab
    - **通径长**:2b²/a = 2p(过焦点垂直长轴的弦)
    - **准线**:x = ±a²/c = ±a/e
    - **焦半径公式**:P(x, y) 在椭圆上 → PF₁ = a + ex, PF₂ = a - ex
  - **3 视图**:
    1. **basic 标准方程**:拖 a(100~320 像素)和 b(60~240 像素)滑块看椭圆拉长压扁 + 动点 P 沿椭圆循环动画 + 实时验证 PF₁+PF₂=2a(高亮黄 = 满足,红 = 不满足)+ F1/F2 焦点 + A1/A2 顶点 + 准线 l1/l2
    2. **parametric 参数方程**:单位圆 → 椭圆映射可视化(a/b 双层虚线圆参考 + 单位圆点(蓝)→ 椭圆动点(黄)映射箭头 + 椭圆动点 → x 轴投影 + θ 角实时显示)
    3. **e-mode 离心率**:固定 a,拖 e 滑块(0.05~0.95)看椭圆从近似圆(e→0)到扁长(e→0.95) + 实时算 b = a·√(1-e²)、c = a·e、p = b²/a
  - **4 预设按钮**:
    - e≈0.05 圆(极限情形)
    - e=0.017 地球(几乎圆)
    - e=0.206 水星(明显扁)
    - e=0.249 冥王星(高度偏心)
  - **教学要点**:
    - 标准方程 + 5 个关键量(a/b/c/e/p)的几何意义
    - 第一定义(几何):PF₁+PF₂=2a(王炸)
    - 第二定义(解析):PF=e·Pd(王炸,与 39 等价)
    - 参数方程单位圆映射(微积分基本公式的具象化)

  - **历史**:
    - 公元前 4 世纪 Menaechmus 用圆锥截线解立方方程 x³=2a³(倍立方问题)
